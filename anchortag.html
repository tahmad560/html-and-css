Types of links in HTML

  • Absulute link in HTML

    Absolute links are links to a full URL, which can be anywhere on the internet. They require the http:// (or https:// ) at the beginning. Clicking on one of these links queries the DNS system to find the server where the content lives.

  • Relative link in HTML

    In HTML, relative links (also called relative URLs) are links that point to a location within the same website or domain, rather than using an absolute path (which includes the full URL, like https://example.com/page).
